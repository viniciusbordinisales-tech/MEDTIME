MEDTIME - versão web (Etapa 1)

1) Instale o Python 3.10 ou mais novo (python.org).
2) Abra o terminal nesta pasta e rode:
     pip install -r requirements.txt
     python web.py
3) Abra no navegador: http://127.0.0.1:5050
   (no celular, na mesma rede Wi-Fi, só se mudar HOST para "0.0.0.0" no web.py)

O banco (medtime.db) é criado sozinho. Para zerar tudo, apague esse arquivo.
Na tela inicial há o botão "Ver com dados de exemplo (fictícios)".
